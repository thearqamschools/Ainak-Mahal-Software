# Ainak Mahal design system 2.0

Original identity: Clear Bridge, concept 01. Two balanced geometric lenses, a restrained teal
bridge and a custom path-only wordmark. Concepts 02 (round) and 03 (browline) were evaluated
for recognisability, balance, small-size clarity and standalone-icon use. Concept 01 is the
most neutral across frames, contact lenses, repairs and clinical records. No reference assets
or unlicensed font files are used. SVG is the master; PNG exports and multi-size ICO are derived.

Navy #142D4E anchors navigation and headings; royal blue #2563EB identifies primary actions;
teal #0D9488 denotes progress; canvas #F8FAFC; white surfaces; text #0F172A; secondary text
#526277 (slightly darker than the suggested slate for readability). Error #B91C1C, success
#15803D and warning #92400E use readable dark text on pale tinted surfaces. Never use colour
alone for status: include a word label.

Segoe UI is a Windows system UI font, 10–11 pt body, 9 pt metadata, 14 pt section title,
24 pt page heading, 26 pt KPI. Do not redistribute the font. 4px base spacing: 8,12,16,24,32.
Buttons and inputs minimum 36 logical pixels; tables 38px rows, left-aligned text, right-aligned
money, sortable headers, alternating subtle rows, visible selection, fixed header with scroll.
Sidebar 220px with grouped navigation; top bar offers global search, user identity, refresh and
F2 shortcut. Content uses flexible Qt layouts; small windows scroll instead of clipping actions.
Forms use labels above inputs, optional markers, inline context and persistent error messages.
Rx uses OD/OS rows and explicit SPH/CYL/AXIS/ADD columns, no ambiguous eye abbreviations alone.

Cards: 1px #E2E8F0 border, 12px radius, 20px padding. Modals: clear title, scrollable form,
Cancel/Save actions, validation keeps entered values. Empty states explain next useful action.
Confirmation is reserved for committing financial records, completed refunds, restoring data
and discarding a cart. Notifications use persistent status text; never hide failure in a toast.
Keyboard: F2 checkout, F3 customers, Ctrl+K global search, Ctrl+Enter checkout; Enter on scanner
field adds the exact/selected match; Escape closes dialogs. Visible blue focus border.

Taste: prioritise one main action, generous whitespace and aligned numeric columns. Motion:
immediate hover/pressed/selection feedback and native popup transitions, no decorative timers,
animated chart transitions or checkout delay. Impeccable: inspect real rendered screenshots,
small-window layouts, tab order, contrast, empty/populated states and functional buttons.
These named skills are unavailable in the catalog; principles are applied directly, not claimed
as installed packages. Original SVG outline utility icons and the original brand mark only.

Runtime assets are bundled locally. No CDN, analytics, cloud account, subscription or runtime
SEO dependency. Logo clear space: at least one lens-height around a lockup; use symbol-only
below 180px width. ICO sizes 16,20,24,32,40,48,64,128,256. Dark variant uses near-white strokes
and a brighter teal bridge. Never stretch, add gradients/shadows or put thin wordmarks at 16px.
